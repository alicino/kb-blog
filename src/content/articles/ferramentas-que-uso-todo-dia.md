Listas de "minhas ferramentas favoritas" costumam ser mais aspiracionais do
que reais. Esta aqui é só o que abre todo santo dia.

## Terminal e shell

Nada muito exótico: um multiplexador de terminal, um prompt que mostra branch
e status do git, e um histórico de comandos que sincroniza entre máquinas.

```bash
# o comando que mais uso no dia a dia
git status --short --branch
```

## Editor

Poucas extensões, mas bem escolhidas. Prefiro um editor rápido com poucas
distrações a um com quinze painéis abertos ao mesmo tempo.

## Gerenciamento de tarefas

Uma lista simples, revisada de manhã. Ferramentas complexas de produtividade
tendem a virar, elas mesmas, uma fonte de procrastinação.

> A melhor ferramenta é a que você esquece que está usando.

No fim, o denominador comum de tudo isso é atrito baixo: o que exige menos
decisões no meio do trabalho ganha meu tempo de tela.
