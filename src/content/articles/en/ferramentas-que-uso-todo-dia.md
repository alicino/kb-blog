"My favorite tools" lists tend to be more aspirational than real. This one is
just what opens every single day.

## Terminal and shell

Nothing too exotic: a terminal multiplexer, a prompt that shows the git branch
and status, and a command history that syncs across machines.

```bash
# the command I use the most, day to day
git status --short --branch
```

## Editor

Few extensions, but well chosen. I'd rather have a fast editor with few
distractions than one with fifteen panels open at the same time.

## Task management

A simple list, reviewed in the morning. Complex productivity tools tend to
become, themselves, a source of procrastination.

> The best tool is the one you forget you're using.

In the end, the common denominator in all of this is low friction: whatever
requires fewer decisions in the middle of the work wins my screen time.
